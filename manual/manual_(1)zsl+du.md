# Kategorie
beschreibung_vortrag

# Definition/ Leitfrage
Beschreibung: Beschreiben Sie, wie Sie die Präsentation beziehungsweise den Vortrag unter Nutzung lerntheoretischer Erkenntnisse aus der Pädaogogischen Psychologie ausgestalten würden.

# Codes
0 = kein Bezug
+1 = Ausgestaltung der Folien auf Grund der Cognitive Load Theorie (Clt) (explizite Nennung der Theorie)
+1 = Ausgestaltung der Folien auf Grund  Cognitive Theory of Multimedia Learning (CTML) (explizite Nennung der Theorie)
+1 = Ausgestaltung der Folien auf Grund des ICAP-Modells (explizite Nennung des Modells)
+1 = evidenzbasierte Prinzipien zur Gestaltung von multimedialen Inhalten (hier auch implizite Nennung bei Ausgestaltung mittels mindestens eines Prinzips)
+1 = Aufbauend von den Modellen würde ich meine Folien so gestalten, dass ich Bilder mit gesprochenem Text kombiniere, die Bilder nahe von geschrieben Text sind, etc. = sprich beispielhafte Ausgestaltung"

# Regeln- und Kodierhinweise
"Punktevergabe in Abhängigkeit der Beantwortung der Fragestellung. Es können CLT, CTML, evidenzbasierte Gestaltungsprinzipien und ICAP herangezogen werden.
+1 pro Theorie und einmalig +1 für Beschreibung der Folienausgestaltung
Erst, wenn in diesem Zusammenhang eines der Wörter ""Gestaltung"", ""gestalten"", ""Ausgestaltung"", ""ausgestalten"", ""Anlehnung"" oder ""anlehnen"" mindestens einmal genannt wird, werden auch Punkte auf die Theorien, das ICAP-Modell oder die evidenzbasierten Prinzipien vergeben werden. "
